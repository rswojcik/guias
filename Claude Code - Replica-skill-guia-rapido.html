Replica Skill — Guia de referência rápida

Conjunto de 11 skills para Claude/Claude Code para planejar, reconstruir, testar, rebrandar e publicar uma versão própria de um aplicativo. Repositório: Jakeschincariol/replica-skill.

MIT Sem cadastro Sem chave de API obrigatória Python 3.8+

Instalação

1. Instalar pelo Claude

Cole no chat do Claude:

https://github.com/Jakeschincariol/replica-skill
install skill

2. Instalar como plugin no Claude Code

/plugin marketplace add Jakeschincariol/replica-skill
/plugin install replica-skill@replica-skill

Os comandos aparecem com namespace, por exemplo: /replica-skill:replica-recon.

3. Instalação global manual

git clone https://github.com/Jakeschincariol/replica-skill.git
cp -r replica-skill/replica-* ~/.claude/skills/

Depois, use comandos sem namespace, como /replica-recon.

4. Instalação por projeto

git clone https://github.com/Jakeschincariol/replica-skill.git
cp -r replica-skill/replica-* caminho/do/seu/projeto/.claude/skills/

5. Usar sem Claude Code

Abra um SKILL.md específico, copie seu conteúdo no início de um chat e instrua o modelo a segui-lo como modo de trabalho. Nesse formato, os utilitários Python do repositório não ficam disponíveis automaticamente.

Usar uma skill isolada

É possível chamar apenas a etapa necessária. Exemplos:

/replica-recon https://exemplo.com
/replica-architect
/replica-entrepreneur
/replica-brand
/replica-deploy

A /replica-entrepreneur, por exemplo, pode ser usada antes da construção para avaliar se vale a pena replicar o produto.

Comandos das ferramentas

Os utilitários usam apenas a biblioteca padrão do Python e não fazem chamadas de rede.

# Comparar layout entre screenshot original e clone
python3 replica-diff/imgdiff.py original.png clone.png --out diff.png

# Calcular score de paridade e itens faltantes
python3 replica-diff/parity.py replica/features.csv

# Analisar avaliações fornecidas em CSV
python3 replica-entrepreneur/reviews.py replica/reviews.csv

# Checar contraste WCAG dos design tokens
python3 replica-design/contrast.py replica/design/tokens.json

# Procurar resquícios do app original no código
python3 replica-brand/sweep.py . --avoid "NomeDoAppOriginal"

# Validar listagem de loja
python3 replica-launch/listing.py replica/launch/listing.json

Testes do próprio repositório

python3 -m unittest discover -s tests -v

Requisitos e limites

Requisitos: Claude ou Claude Code; Python 3.8+ somente para os utilitários; nenhum pacote via pip é exigido pelas ferramentas do repositório. Para recursos reais do app, podem ser necessárias contas/chaves próprias, como Stripe, e-mail ou APIs de terceiros.
Uso responsável: o método é para reconstruir funcionalidades e padrões de UX em estilo clean-room. Não copie código-fonte, logotipos, textos, assets, APIs privadas ou conteúdo proprietário. Faça rebranding antes do deploy e revise marcas registradas, termos de serviço e restrições contratuais antes de monetizar.
